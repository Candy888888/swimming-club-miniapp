# 新升潮游泳馆小程序

## 项目介绍

这是一个游泳馆小程序，提供场馆预约、课程报名、泳队介绍、赛事活动等功能。

## 功能列表

- 首页：展示游泳馆信息、活动推广、泳队介绍和推荐视频
- 约课：提供课程预约和场馆预约功能
- 赛事：展示游泳比赛和活动信息
- 泳队：介绍各级别泳队和教练团队
- 我的：个人中心，包括会员卡、课程记录等

## 页面结构

- 首页：大Banner轮播、功能导航区、小Banner轮播、泳队介绍、推荐视频
- 底部导航栏：首页、约课、赛事、泳队、我的

## 开发说明

本项目使用微信小程序原生开发，需要在微信开发者工具中打开。

### 开发环境

- 微信开发者工具
- 小程序基础库版本：2.19.4+

### 目录结构

```
├── pages/                 # 页面文件夹
│   ├── index/             # 首页
│   ├── booking/           # 约课页面
│   ├── events/            # 赛事页面
│   ├── team/              # 泳队页面
│   └── profile/           # 个人中心页面
├── images/                # 图片资源
│   ├── banner/            # 轮播图
│   ├── icons/             # 图标
│   ├── teams/             # 泳队图标
│   ├── videos/            # 视频封面
│   └── tabbar/            # 底部导航栏图标
├── app.js                 # 应用入口文件
├── app.json               # 全局配置
├── app.wxss               # 全局样式
└── project.config.json    # 项目配置
```

## 使用说明

1. 克隆本仓库
2. 使用微信开发者工具打开项目
3. 在app.json中修改appid为您的小程序appid
4. 编译运行

## 注意事项

- 本项目中的图片资源需要自行添加
- 接口数据需要自行对接后端服务
